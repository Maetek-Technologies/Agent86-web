# agent86-web v0.4.0

What agent86 1.0.19 and 1.0.20 add over ACP, in the browser.

```sh
npm install -g agent86@latest       # 1.0.20 for everything below; 1.0.15 or newer still works
npm install -g agent86-web@latest
```

Every feature is detected from what agent86 sends or advertises, never from its version. With an older agent86, each looks as it did in 0.3.0.

## New

- **Real diffs.** agent86 1.0.19 sends a file edit's whole file before and after (ACP `diff` content). The approval and the finished card show a diff built from them, with line numbers and highlighting, a new file as all added lines, and **whole file** to see the unchanged lines too. The same change is never shown twice. Without them (agent86 before 1.0.19, a reopened session, or a file over 256 KiB), the text diff shows as before.
- **Where a call works.** File tool cards show the file and the first changed line, relative to the workspace, with a copy button. Search tools (`search_files`, `find_files`) have an icon of their own.
- **Context and cost** (agent86 1.0.20). The thread header shows how much of the model's context window the last request used, and what the session has cost. When agent86 has no price for the model, it says **cost n/a**, never $0.00.
- **Compaction** (agent86 1.0.20). When agent86 compacts a long session into a summary, the thread shows one **Context compacted** entry, which opens to the summary (or says why it failed).
- **agent86's state events** (agent86 1.0.20, when it advertises them):
  - each turn's end shows its model calls (step, model, tokens, cost) and its spend against `[limits] max_cost_usd`, with a meter while the turn runs;
  - a delegation card shows its sub-agent's status, model calls, and total cost;
  - a guardrail finding shows as one quiet line, with the findings on request;
  - the header shows the model triage routing chose.

## Fixed

- With agent86 1.0.19, an edit's result showed a stray `diff <path>` line above the text diff.

## Upgrading

Nothing to change. Sessions reopened from before agent86 1.0.19 show text diffs, as agent86 replays them that way.

## Security and privacy

- The bridge still forces files and terminal off in `initialize`, and now lets two opt-ins through, `session.compaction` and agent86's state events, which only change how agent86 reports. Any other claim is dropped (T9 in [docs/SECURITY.md](https://github.com/Maetek-Technologies/Agent86-web/blob/main/docs/SECURITY.md)).
- File contents from diffs stay in memory with the tool call, like tool output; they are never written to the logs or the browser's storage. agent86 redacts its state events as it does its trace.

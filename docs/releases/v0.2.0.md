# agent86-web v0.2.0

Polish for the browser shell, plus support for agent86 1.0.17.

```sh
npm install -g agent86      # 1.0.15 or newer; 1.0.17 or newer recommended
npx agent86-web --root ~/code
```

## What's new

- **Rename threads.** Double-click a tab's name (or press F2), or use the pencil on a session in the sidebar. With agent86 1.0.17 or newer, the name is saved in agent86, so `/resume` at a terminal and other browsers see it too. With older versions, it is kept in this browser.
- **Each workspace lists its own sessions** with agent86 1.0.17 or newer. Before, sessions started at a terminal showed up under every workspace.
- **A resizable sessions panel.** Drag its edge (or use the arrow keys on it); double-click to reset. Its width and whether it is shown are remembered.
- **Quit.** ⏻ in the top bar stops agent86-web and every agent86 it started, after a confirmation that names any running turns or waiting approvals. The tab closes, or says agent86-web has stopped.
- **A default approval mode** for new threads, under **Settings & about** (the agent86 version button). `auto` asks for confirmation first. It applies once, when a thread is first opened in the browser.
- **A more useful logs drawer:** agent86-web's own connection events (connected, session started or reopened, reconnecting and why, restarted after trust, renamed), a copy button, and a badge when agent86 ignored project settings that need trust. agent86 itself writes notes only about problems and notable events, so a quiet drawer is normal.
- The header reads **AGENT86**, and the trusted-projects list explains when a project needs trust.

## Upgrading

Nothing to change. Names you gave threads with an older agent86 are sent to agent86 the next time the session is open and idle after you upgrade agent86 to 1.0.17.

Sessions saved at a terminal before agent86 1.0.17, and never opened from a folder since, no longer appear in the sidebar. Resume one at a terminal in its folder (`agent86 --resume <id>`) to bring it back.

## Security

- `POST /api/shutdown`, behind the same cookie, origin, and header checks as the other changes (T19 in [docs/SECURITY.md](https://github.com/Maetek-Technologies/Agent86-web/blob/main/docs/SECURITY.md)).
- The default approval mode is per browser, off by default, and `auto` needs its own confirmation (T20).

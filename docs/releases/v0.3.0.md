# agent86-web v0.3.0

Settings that last across reloads, restarts, and browsers.

```sh
npm install -g agent86-web@latest
agent86-web --root ~/code --port 8686 --save-port   # once; later just: agent86-web --root ~/code
```

## Fixed

- **The default approval mode is kept.** In 0.2.0 it was saved in the browser, which keeps data per address, and agent86-web picked a new port each time it started, so the setting was lost on every restart. It is now kept by agent86-web itself, in `~/.agent86-web/settings.json`, and applies in every browser.
- **Each thread keeps its mode and model.** agent86 does not save either with a session: reopening one (after a reload, after agent86 was stopped for being idle, after trusting a project, or after a restart) starts it in agent86's defaults. agent86-web now remembers both for each thread and sets them again before the thread is shown, so no turn runs under the wrong approvals. A model from a provider's live list is set once agent86 lists it; if it is gone, the thread says so.

## New

- **make default** next to a thread's mode selector sets the default from that thread. Choosing `auto` asks first, as in _Settings & about_.
- **The same port every time.** `agent86-web --port 8686 --save-port` saves the port; later starts use it. `AGENT86_WEB_PORT` and `--port` still win for one run, and `--port 0 --save-port` forgets it. If the port is taken, agent86-web says so and stops, rather than quietly using another port. With a fixed port, the browser also keeps your open threads, recent workspaces, and prompt history across restarts.
- **Reusing a tab:** opening a new launch link in a tab that is still open on the same port signs it in again.

## Upgrading

A default mode chosen in 0.2.0 moves to agent86-web's settings the first time you open the app in that browser (if 0.2.0 still had it, which needed a fixed `--port`).

## Security

- The default mode is changed only through `POST /api/settings`, behind the cookie, origin, and header checks, and only to `ask`, `auto`, or `deny`. The settings file is readable only by you. The page cannot change the port. See T20 and T21 in [docs/SECURITY.md](https://github.com/Maetek-Technologies/Agent86-web/blob/main/docs/SECURITY.md).

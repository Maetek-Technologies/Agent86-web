# agent86-web v0.1.0

The first release of agent86-web, a browser interface for [agent86](https://github.com/Maetek-Technologies/agent86).

```sh
npm install -g agent86      # 1.0.15 or newer, with a model key
npx agent86-web --root ~/code
```

## What it does

- **Conversations** with agent86 in the browser. Replies and reasoning stream as Markdown, with highlighted code. Esc or Stop cancels a turn.
- **Tool calls as cards,** and approvals with the diff, the new file, or the command in view. Number keys answer, and Esc rejects.
- **Several threads at once** in tabs, kept across reloads. A reload mid-turn waits for the turn and then reopens the session.
- **Saved sessions** per workspace, including ones started at a terminal. `agent86 --resume <id>` continues a browser session at a terminal.
- **Settings and input:** a workspace picker limited to `--root`, model and approval-mode selectors, the `/` command menu, `@` file mentions, prompt history, and agent86's notes in a logs drawer.
- **Project trust:** review a project's `.agent86/config.toml` and trust it, so its MCP servers and other settings apply. Trust is remembered per file, by hash.
- **Update notice:** at most once a day, a notice when a newer agent86 or agent86-web is out (`--no-update-check` turns it off).

## Security

- **Access to the bridge:** it listens on loopback only. The browser signs in with a one-time token, then holds an `HttpOnly`, `SameSite=Strict` cookie.
- **Request checks:** every request is checked for its `Host` header, and every WebSocket and change for its `Origin` and a CSRF header.
- **The page:** a strict Content-Security-Policy applies, and raw HTML from the model is never rendered.
- **Limits on the page:** threads can only run under `--root`, a page cannot add MCP servers, and a socket that floods the bridge is closed.

The threat model and the review are in [docs/SECURITY.md](https://github.com/Maetek-Technologies/Agent86-web/blob/main/docs/SECURITY.md).

## Known limits

- **Terminal only:** model and MCP setup (`/config model`, `/config mcp`) and entering secrets. The protocol doesn't allow asking for secrets in a form.
- **File mentions** reach agent86 as links. The model reads the file itself.
- **Live cost:** none. `/cost` answers on demand.
- **Remote use:** only through an SSH port forward.

Tested with agent86 1.0.15 on Linux, macOS, and Windows (unit tests), and end to end in Chromium against both a mock agent and the real agent86.

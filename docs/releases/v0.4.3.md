# agent86-web v0.4.3

Easier-to-read answers to `/tools`, `/skills` and `/agents`, and the agent is now called "Agent 86" throughout the page.

```sh
npm install -g agent86-web@latest
```

Works with the same agent86 versions as 0.4.2 (1.0.15 or newer; 1.0.23 for everything).

## Changed

- **`/tools`, `/skills` and `/agents` show as lists.** agent86 answers these with text laid out for a terminal, which ran together into one paragraph in the browser. Each answer is now a card:
  - **Tools:** how many there are, agent86's built-in tools, then each MCP server's tools in their own group, without the `mcp__server__` prefix.
  - **Skills:** each skill's name, description, and the tools it may use while active, with how to run one.
  - **Sub-agents:** each sub-agent's name, where it comes from (built-in, user, project), and description, with how to run one.

  An answer in any other form, such as "no skills discovered", shows as before.
- **"Agent 86".** The page's text, tab title, message box, headings, tooltips and logs now say "Agent 86", and the header says "AGENT 86". Commands you type at a terminal (`agent86`, `agent86-web`) and `.agent86/` paths are unchanged.

## Upgrading

Nothing to change.
